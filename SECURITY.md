# Security policy

## Supported version

Security fixes are applied to the latest version on `main` and released through the normal production workflow.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in the repository Security tab. This keeps the report private while it is investigated.

Do not include passwords, access tokens, customer data, or other secrets in a public issue.

Include a concise description, affected page or component, reproduction steps, and the potential impact. You should receive an initial response within seven days.
