This cluster answers five distinct questions without exposing or indexing private product routes.

| Route | Primary question | Status |

| `/coffee-journal` | How do I keep a personal coffee journal I will continue using? | Already implemented; unchanged in this batch |
| `/coffee-tasting-notes` | How can a non-expert write useful coffee tasting notes? | Editorial review |

Each new guide has its own canonical URL and Article structured data, links naturally to sibling guides and signup, and is included in the sitemap. Existing `robots.ts` continues to exclude `/space/`, `/api/`, and authentication routes.

## Sustainable publishing cadence

Do not add more search pages immediately. Publish this cluster as one baseline release, submit the sitemap, and allow at least four weeks of Search Console data before choosing the next topic.

Review monthly during the first three months:

- indexed page count and coverage errors;
- impressions and queries per guide;
- click-through rate by query and page;
- signup-path visits originating from guides;
- queries receiving impressions but not a useful answer.

After the baseline period, publish at most one genuinely useful guide or one substantive update every two to four weeks. Choose work from observed queries and product questions, not keyword variants. Update an existing guide when the intent overlaps; create a new guide only when it answers a distinct user question.

Avoid thin doorway pages, copied retailer descriptions, invented expertise, and structured data that is not visible or accurate on the page.
